# Browser/desktop deployment on Vercel

Import https://github.com/moontasir-me/MafiaGame at https://vercel.com/new.

Keep Root Directory at the repository root. The checked-in vercel.json selects Other, skips installation/build, and publishes www. Click Deploy. No environment variables are required for shared-screen play. Open the resulting HTTPS URL in a desktop or phone browser. Future pushes to main deploy automatically once the repository is connected.

## What this deployment supports

The single-screen host game, all three worlds, four-digit PINs, timers, local rankings, profiles, and artwork work in the browser. Saved games and scores are local to each browser/device.

## QR multiplayer

The current Node/Android room service keeps rooms in memory on the original host. Static Vercel hosting does not run server.mjs or provide the /api endpoints. Do not use the separate-phone Create room flow on this deployment: it requires the local Node server or Android host app.

For desktop LAN multiplayer, run npm start on a computer, connect everyone to the same network, and use the local invitation generated by the host. Android hotspot rooms continue working independently of Vercel.

Online multiplayer on the Vercel URL needs a hosted API with durable shared room state and suitable authorization/origin handling. It is not enabled by this static deployment. Avoid deploying the current in-memory service as stateless function handlers; clients could reach different instances and lose room state.
